# Hardware

The first physical target is an ugly but fast two-motor test rig. Keep it light, expose enough access for measurement, and do not treat it as cat-safe until it is fully enclosed.

Start by testing:

- Motor placement: front, middle, rear.
- Motor orientation: horizontal, vertical, diagonal.
- Leg materials: bristles, TPU, wire, silicone.
- Battery placement: centered, front-biased, rear-biased.
